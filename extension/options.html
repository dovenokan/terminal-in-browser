Terminal settings

Changes are saved as you make them and apply to open terminal tabs right away.

PS C:\> Get-ChildItem -Recurse

Shortcuts

Alt+Shift+PNew terminal tab (change it in the browser's extension shortcuts page)
Ctrl+C / Ctrl+VCopy selection / paste; right-click does either
Ctrl+Shift+FFind in scrollback
Ctrl+Shift+MRender selected output as Markdown with LaTeX
Ctrl+clickOpen a link
